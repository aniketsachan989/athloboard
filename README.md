# ⚡ Athloboard — Web Platform

Official website for verified gym facility audits, laboratory-tested sports nutrition, national powerlifting rankings, and sanctioned championships.

---

## 🏛️ Features

- **🏋️ Verified Gyms Directory (`search-gyms.html`)**: Audited Phase 1 & 2 equipment capacities (total plate kg, dumbbell kg, trainer counts, certified photos).
- **🧪 Lab-Tested Marketplace (`marketplace.html`)**: 100% HPLC verified sports nutrition and gear.
- **🏆 National SBD Leaderboard (`leaderboard.html`)**: Video-refereed Squat, Bench Press, and Deadlift powerlifting records.
- **📅 Sanctioned Meets (`competitions.html`)**: National and state championship schedules and entries.
- **📍 GPS City Radar (`city-map.html`)**: Interactive city map locating verified gym facilities and local supplement shops.
- **🏢 Partner Enrollment & Login (`signup.html`, `login.html`)**: Registration and management consoles for Gym Owners, Brands, and Local Vendors.

---

## 🚀 Quickstart

Run a local static server:
```bash
python -m http.server 8080
```
Open `http://localhost:8080/index.html` in your browser.
